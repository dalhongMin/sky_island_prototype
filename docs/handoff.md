## 주요 구조

- `scripts/state/sky_island_state.gd`: 성장 단계, 돌보기, 낮밤, 고래 방문의 단일 상태 소스.
- `scripts/world/`: 섬 성장 연출, 하늘 주기, 구름, 고래의 화면 표현.
- `scripts/art/`: 절차적 저폴리 메시와 공용 재질. `island_shell.gd`는 단계별 연결 지형과 실제 삼각형 표면 높이를 제공한다. `whale_mesh.gd`는 둥근 머리, 지느러미, 갈라진 꼬리, 표면 발광 무늬를 만든다.
- `scripts/main.gd`, `scripts/camera_rig.gd`: UI·월드 포인터 소유권과 지속되는 궤도 카메라. GUI보다 먼저 입력 생명주기를 관찰해서 UI 위의 해제를 놓치지 않는다.
- `scripts/ui/hud.gd`, `scenes/hud.tscn`: 임시 조작 UI. 한국어 폰트가 없어 영어 자리표시 문구다.
- `tests/prototype_test.gd`: 헤드리스 상태·구조 검사.
- `tools/capture_prototype.gd`: GUI 렌더 캡처 8장을 `docs/images/`에 저장. 기존 6장 외에 회전·확대 화면을 포함한다.

## 조작 — 2026-10-03 개편

- 마우스 왼쪽 드래그 또는 한 손가락 드래그: 섬 중심으로 수평 360도 회전, 수직 각도는 15~60도로 제한.
- 마우스 휠, 트랙패드 핀치, 두 손가락 핀치: 확대·축소. 확대 시 화면 가장자리 일부가 잘리는 것은 의도된 관찰 모드다.
- 섬을 짧게 누르거나 돌보기 버튼: 성장. 드래그·핀치·취소 입력은 돌봄으로 계산하지 않는다.
- `Reset view`: 고래를 볼 수 있는 기본 세로 구도로 복귀. 손을 놓아도 자동 복귀하지 않는다.
- UI를 누른 포인터가 남아 있는 동안 다른 손가락·휠의 월드 입력을 막는다. 실기기 핀치 감각은 별도 검증 대상이다.

## 지형 주의점

여러 완전한 바위 덩어리를 겹치던 구현은 연결된 단계별 외곽으로 대체했다. 화면에는 한 단계의 지형 메시만 표시하고, 이전 단계의 나무·꽃·길은 유지한다. 소품 배치는 설계 높이 함수만 믿지 말고 실제 삼각형 표면 높이와 이후 단계의 높이 차이도 확인해야 한다.

## 범위와 한계

이 빌드는 작은 섬이 3단계 커지고 낮·노을·밤으로 하늘이 바뀌며, 완전히 자란 밤에 하늘고래가 지나가는 장면을 시험한다. 성장 탭 수는 데모 속도용 수치다. 장기 경제·레벨 밸런스·저장·광고·결제·다수 섬·완성 아트는 구현하지 않았다. 별도 게임으로 만들지, 기존 밤의 온실 기획과 연결할지는 결정하지 않았다.

데스크톱 Metal의 Mobile 렌더러 캡처는 모바일 실기기 성능 검증이 아니다. Android/iOS 실행, 터치 감각, 배터리·발열·FPS는 아직 확인이 필요하다.
