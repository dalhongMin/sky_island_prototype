# 떠 있는 섬 — 첫 수직 시각 프로토타입

상태: 2026-10-03 검증용 설계. 본게임 기획·수익화·밸런스 확정 아님.

## 검증 질문

1. 숫자 보상 없이도 플레이어가 작은 섬을 돌보고 다음 모습을 보고 싶어 하는가?
2. 섬이 자라는 세 순간이 모바일 세로 화면에서 분명히 읽히는가?
3. 낮에서 밤으로 바뀌는 풍경과 하늘고래 방문이 이 프로젝트만의 감정을 만드는가?
4. 이 연출을 작은 모바일 3D 제작 범위로 감당할 수 있는가?

## 60~90초 체험

- 시작: 작은 로우폴리 바위섬, 어린 나무/풀, 넓은 하늘, 구름. 온실은 없다.
- 플레이어가 섬을 몇 번 돌보면 섬이 **세 단계로 영구 성장**한다. 흙·풀 확장 → 꽃/나무/길 → 절벽/작은 물·빛 풍경으로 모습이 달라진다. 이전 구역의 생명과 진행은 유지한다. 누르는 횟수는 프로토타입용이며 장기 경제가 아니다.
- 밝은 낮/노을/별이 뜬 밤이 부드럽게 전환된다. 밤에는 식물·작은 등불이 빛나지만 과한 광원은 쓰지 않는다. 낮밤은 시각 리듬이며 대기 강제나 놓치는 보상을 만들지 않는다.
- 섬이 충분히 자란 밤에는 고래 한 마리가 하늘을 천천히 지나가고 다시 사라진다. 첫 방문은 데모 내 확실히 볼 수 있어야 한다. 방문은 감정적 장면이며 수집·재화 지급·로그인 타이머는 추가하지 않는다.
- UI는 현재 단계와 돌보기 입력을 알아볼 만큼만 둔다. 실루엣·풍경을 UI가 가리지 않는다.

## 조작과 공간 — 2026-10-03 추가 승인

- 사용자가 확대와 회전을 요청했다. 수평으로 섬을 한 바퀴 둘러볼 수 있고, 수직 각도와 확대 거리는 제한한다. 초기의 ±10도 제한은 이 프로토타입에서 해제한다.
- 마우스 드래그/한 손가락 드래그로 회전, 휠/핀치로 확대·축소, 짧은 섬 탭과 돌보기 버튼으로 돌본다. 드래그 돌봄은 회전 조작으로 대체한다.
- UI를 누르거나 핀치하는 입력이 섬 돌보기로 이어지지 않아야 한다. 바라보던 각도를 유지하고 원위치 버튼으로 기본 구도에 돌아간다.
- 지형은 연결된 하나의 외곽과 절벽을 갖는다. 성장 때 완전한 바위 원뿔 여러 개를 포개는 방식은 피한다. 높은 어깨 지형과 연못은 연결된 지형의 윤곽으로 읽혀야 한다.
- 고래는 둥근 머리·밝은 배·넓은 지느러미·갈라진 꼬리를 가진 저폴리 형태로 다듬는다. 발광 무늬는 몸 표면에 붙여 표현한다.

## 시각 원칙

- 로우폴리 디오라마, 읽기 쉬운 큰 형태, 제한된 색 팔레트, 따뜻한 낮과 깊은 푸른 밤.
- 큰 기하와 적은 재질을 재사용한다. 동작은 공통 루프(섬의 미세한 부유, 구름 이동, 풀/잎 흔들림, 빛 호흡)와 성장·고래의 핵심 연출로 집중한다.
- 모바일 실기기 성능은 아직 미검증. 실제 광원·투명 면·메시 수를 관리하고 데스크톱 Metal Mobile 캡처를 기준 이미지로 보관한다.

## 첫 프로토타입에서 제외

기존 클릭커 경제, 25노드 나무, 환생/별, 상점·광고·결제 연결, 저장/오프라인, 다수 식물·고래, 여러 섬, 날씨·계절, 자유 이동 카메라, 최종 사운드/모델 아트. 기존 수익화 기획의 삭제 결정은 별도다.
