# 공중섬 진행 로드맵

기준일: 2026-10-06. 현재 진행 대상은 공중섬이며 기존 밤의 온실은 참고용으로 유지한다. 이 문서는 작업 순서이며 미승인 기능의 구현 지시가 아니다. 설계는 vision.md, 완료 사실은 status.md, 변경 이력은 work-log.md를 따른다.

## 1. 수직 시각 프로토타입

구현 및 데스크톱 검증 기록 있음(2026-10-03), 모바일 미검증. 돌보기 → 섬 3단계 성장 → 낮/노을/밤 → 하늘고래 방문, 세로 화면과 회전·확대·원위치가 대상이다. 당시 자동 검사 177개 통과와 기준 캡처 8장이 기록돼 있다. 최종 아트·장기 재미·실기기 성능 검증은 아니다.

## 2. 직접 플레이 및 모바일 검증 — 다음 작업

- 데스크톱에서 60~90초 체험의 성장 가독성, 돌봄/회전 분리, 고래 시인성을 직접 확인한다.
- 목표 Android/iOS 기기와 프레임 목표를 먼저 정하고 기기·OS·빌드·측정 조건을 기록한다.
- 터치·핀치·UI 중 다중 입력·취소·초점 상실과 확대/360도 회전 시 지형·배경을 확인한다.
- FPS·메모리·발열을 실제로 측정하고 문제와 해결 여부를 기록한다.

완료 조건: 직접 플레이 결과와 대상 실기기별 입력/성능 결과가 기록되고, 발견된 문제의 처리 상태가 명확하다. 장기 재미 검증은 별도로 남긴다.

## 3. 미감과 체험 방향 결정

플레이 결과를 바탕으로 원하는 감정과 성장 변화가 읽히는지 판단한다. 절차적 자리표시 아트의 고도화 범위를 정하고 후보 이미지·비교·승인을 기록한다. 대량 에셋은 성능 기준을 정한 뒤 제작한다.

완료 조건: 유지할 콘셉트, 아트 범위, 다음 구현 목표가 사용자 결정으로 문서화된다.

## 4. 장기 게임 설계 — 미확정·별도 승인

장기 성장 루프·콘텐츠·저장·오프라인·경제·수익화·사운드·출시 범위는 필요성을 논의한 뒤 설계한다. 기존 온실 게임과 연결할지 독립 제품으로 만들지도 미결정이다. 기존 경제 기획을 삭제하거나 자동 이식하지 않는다.

완료 조건: 제품 방향과 시스템별 범위·규칙·검증 기준이 승인된 이후에만 구현 작업으로 나눈다.

## 5. 제품화와 배포 — 미착수

승인된 제품 범위 구현 → 회귀·실기기 품질 확인 → 플랫폼/서비스 설정 → 배포 순서로 진행한다. 실제 광고·결제 연결과 외부 배포는 별도 승인 대상이다.

## 작업 카드 규칙

각 작업은 목표, 담당자, 허용 파일, 의존 작업, 완료 조건, 검증 방법을 포함한다. Nimbalyst는 관리 화면으로 사용하며 계획·진행·리뷰·검증 완료 상태를 구분한다. 완료된 세션도 저장소 문서와 실제 변경을 확인한 뒤 완료로 판정한다.
